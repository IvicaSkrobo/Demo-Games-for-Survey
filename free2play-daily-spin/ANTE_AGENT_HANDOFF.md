## Publish the same version on another site

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

1. Build from the selected tag/commit with the committed npm lockfile. Record `git rev-parse HEAD` in the hosting release notes.
2. Upload **all contents of `dist/` together**, preserving relative paths. Include `index.html`, `money.html`, `legacy.html`, lab pages and the whole `assets/` tree. Copying only the HTML, only the Spine export or an old `dist/` from another checkout will mix versions.
3. The build uses relative base paths and supports a static host or subdirectory. Open through HTTP(S), not `file://`. Configure the host to serve the emitted HTML files directly; a blanket SPA rewrite must not replace `money.html` or `legacy.html` with `index.html`.
4. Open the new site root: it must show **Glavna igra / Prototipovi / Animacijski demo**. Main = Ante collector/reels + our magenta energy rail and round animated button. Prototypes = Blender/Chest. Also open `?version=ours` and `?version=ante`: both must show the main game.

6. The animation-demo header link deliberately points to the preserved public reference on Demo Games. It is a separate snapshot, not the new host's working game. The `dist/` build does not regenerate or overwrite that old snapshot.
7. Send back the new hosted URL **and source commit/tag**, so everyone can identify which game is deployed. Until that check is done, an older hosted copy is not evidence of the current source.

For the existing Demo Games repository, publish `dist/` into `free2play-daily-spin/` and preserve its nested `money-machine-handoff/` folder. ## Confirmed working rules

- Lightning counter 3/3 grants 3 free spins, consumed before energy; partial progress and banked free spins are saved locally.
- Three lightning symbols on one payline refill energy and complete the counter once.
- Energy maximum starts at 5 and increases by 1 every 3 consecutive days: day 4 = 6, day 7 = 7, day 22 = 12.
- Regeneration is +1 per 60 minutes, derived from timestamps. Existing saved checkpoints can retain an earlier already-scheduled recharge; new intervals use the current duration.
- Keep Ante's collector state/clip ordering and reel motion. Use the reused Blender components for streak/energy/button presentation.

## Current decisions and remaining production work

- Streak decay is now confirmed by Ivica for the working game: −1 per missed calendar day, minimum 1. Energy capacity falls only when crossing a three-day threshold. Included in the r2 release. The first tag remains a historical snapshot.
- Collector continuation is now confirmed and implemented locally: Final Reward → authoritative test payout → next collector at 5% (50/1000, configurable). Payout defaults to 100 test coins; real coin valuation remains open. Reset is only a test tool. The frozen animation demo still stops at the end; r2 includes the repeatable working loop.
